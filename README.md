# 📚 The Book: Онлайн-библиотека с элементами RPG

Курсовой проект по дисциплине "Разработка программного обеспечения".
Сервис для чтения книг с системой геймификации: получайте изумруды за чтение, поддерживайте ударный режим (streak) и коллекционируйте редкие карточки.

## 🚩 1. Определение проблемы

Студентам и любителям чтения сложно поддерживать мотивацию для регулярного чтения литературы из-за отсутствия вовлекающих механизмов. Существующие электронные библиотеки предлагают только функционал "читалки", что делает процесс рутинным. Пользователи теряют интерес к чтению, так как не получают мгновенного позитивного подкрепления своего прогресса.

## 🛠 2. Технологический стек

*   **Backend:** .NET 8 (C#), ASP.NET Core Web API
*   **Database:** PostgreSQL 16 (Entity Framework / ADO.NET logic)
*   **Frontend:** HTML5, CSS3, Vanilla JS (Nginx для раздачи статики)
*   **Infrastructure:** Docker, Docker Compose
*   **Testing:** xUnit (Unit/Integration), k6 (Load Testing)

## 📋 3. Требования и Пользовательские истории

### Целевая аудитория и нагрузка
*   **DAU (Daily Active Users):** ~10,000 пользователей.
*   **Период хранения данных:** > 5 лет (история чтения, коллекция карт).

### Основные сценарии (User Stories)
1.  **Чтение и Награды:** *Как пользователь, я хочу, чтобы время, проведенное за чтением, отслеживалось, и я получал внутреннюю валюту (изумруды), чтобы иметь мотивацию читать больше.*
2.  **Ударный режим (Streak):** *Как пользователь, я хочу видеть индикатор своего ежедневного прогресса (огонек), который гаснет, если я пропускаю день, чтобы стимулировать меня заходить в сервис ежедневно.*
3.  **Магазин и Коллекционирование:** *Как пользователь, я хочу тратить накопленные изумруды на покупку случайных коллекционных карточек (Gacha-механика), чтобы соревноваться с друзьями редкостью коллекции.*


## 🏗 4. Архитектура и Проектирование

### Характер нагрузки
*   **Соотношение Read/Write:** 95% / 5% (Пользователи в основном читают книги и просматривают каталог, запись происходит только при регистрации, получении наград и покупках).
*   **Трафик:** При 10k DAU и среднем времени чтения 30 мин, ожидается пиковая нагрузка ~50-100 RPS.
